# Good4 V2 — iPhone App Store görselleri

27 Eylül 2026 tarihinde gerçek Good4 V2 iPhone ekran görüntülerinden hazırlanmıştır.

- Boyut: **1320 × 2868 px (iPhone 6,9 inç App Store boyutu)**.
- Biçim: **24 bit RGB PNG**, şeffaflık içermez.
- Tasarım: aynı limon yeşili arka plan, Türkçe başlıklar ve Dynamic Island içeren iPhone çerçevesi.
- Uygulama arayüzü yeniden çizilmemiştir; ekran görüntüleri yalnızca çerçeveye sığacak şekilde ölçeklendirilmiştir.
- PNG dosyalarında ek metin, EXIF veya diğer metadata bulunmaz.

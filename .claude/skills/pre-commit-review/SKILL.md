# Commit öncesi review

Repo köküne göre [.agents/skills/good4-code-review/SKILL.md](../../../.agents/skills/good4-code-review/SKILL.md) dosyasını oku ve uygula. İnceleme kapsamını staged/unstaged değişiklik veya istenen branch/PR'ye göre belirle; commit öncesi rapor biçimini kullan.

Bu skill review çalıştırır. Kullanıcının açık talebi veya oturumdaki mevcut yetkisi olmadan commit, push, PR ya da deploy yapma. Tekrarlanan denetim listesini burada tutma; ortak review kaynağını kullan.
